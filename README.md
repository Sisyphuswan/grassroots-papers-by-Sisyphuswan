# grassroots-papers-by-Sisyphuswan
Store thoughts and reflections  

**郑重声明**：  
本人并非学术界研究人员，这些项目**不以在学术期刊发表为目的**。它仅仅是我在阅读一些书籍后，产生的一点灵感延伸。我试图站在先哲铸造的大厦中，用通俗的语言和基础的验证，完成一点“微不足道的装修工作”。  

我将所有思考、公式推演和图表开源，是希望它能成为一个**公共的思想沙盒**。欢迎任何人阅读、挑刺、修正或扩展。
